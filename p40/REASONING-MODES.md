# Model capabilities

High/XHigh retain the model's standard meaning. The separate author Auto/Adaptive/Ultra capabilities belong only to the specific qualified DavidAU source identity; other models use their own native modes. A model name alone grants no capability. Manifest identity and API checks must agree.

The app and `strata.json` are model-neutral. No author persona, memory service, database or embedder is installed for another model. Available modes are advertised by the loaded model, not inferred from a client label.
