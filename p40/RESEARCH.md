# Review scope

Current maintenance covers Niko1221/Strata and the primary PolyStrata/Project Maya forks: source changes, applicable PRs/issues and updated discussion. Main inventory and body screening are distinct from full code review. This release does not claim an exhaustive review of repository history.

Selected changes have exact source/license and validation records. Foreign GPU/ISA results, routing changes and numerical shortcuts are not treated as free P40 acceleration. Deferred or unverified ideas are not enabled. See CHANGES.md and source-provenance.json for this build.
