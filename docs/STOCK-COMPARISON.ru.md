# Отличия от stock Strata 1.56

База сравнения — [официальный commit `ffa80d73133e`](https://github.com/Niko1221/Strata/commit/ffa80d73133ea5c548aefe57889a16e8085a938f). Ниже — проверенная локальная интеграция; опубликованный ZIP r2 имеет отдельную версию. Этот список не означает, что новый исходный код или бинарный пакет уже опубликован.

- **AVX1/Pascal:** отдельный профиль для Ivy Bridge и P40, строгая CPU/host FP и проверяемый отказ от привязки потоков.
- **CPU-кернелы:** native dispatch Q2_0 на AVX1, дополнительные IQ/Q2 row-оптимизации и преобразование half без F16C.
- **P40-кернелы:** Pascal MMQ overlay и узкий выбор Q6_K head-вариантов; явные пользовательские overrides сохраняют приоритет.
- **Загрузка модели:** перекрытие чтения expert arena и dense-весов; параллельные Windows CUDA uploads с ожиданием завершения и последовательным fallback.
- **MTP/lookup:** возврат памяти неиспользуемых target-графов при OOM захвата MTP-графа в проверенном single-GPU serial-serving пути; лимиты окон не уменьшаются.
- **Жизненный цикл:** graceful-only выход управляемых engine/vision, ожидание принятых запросов и запрет замены неподтверждённого owner; исправлены потерянные queue wakeups из PR4738.
- **MiniMax M3.1-Flash:** интеграция отдельного native backend из Project Maya, DSpark, собственного tokenizer и формата tool calls. Совместимый MiniMax Q2-draft пока не подтверждён.
- **API:** строгая граница текущего каталога tools, дополнительные проверки буферизации аргументов, JSON-массивов, частичных Responses и формата Anthropic; socket-stall и неожиданные ошибки обрабатываются отдельно.
- **Границы памяти:** защита GGUF от переполнения длины, безопасное завершение неинициализированного PLE reader, MMQ tail bounds и сохранение BF16 NaN.
- **Семейные режимы:** авторские Auto/Adaptive/Ultra отделены от native efforts; управляемый запуск требует подготовленную модельную идентичность. Для других семейств используются собственные шаблоны и режимы.

## MiniMax: локально проверенная экспериментальная интеграция

Эта часть описывает локальную интеграцию после сравнения выше. Она ещё не включена в опубликованный ZIP r2; сам r2 и его assets не изменены.

- Исправлен выбор архитектуры при запуске MiniMax: используются её собственные thinking-маркеры, EOS и parser. Реальный API-запрос подтвердил непустой итоговый `content` без сырых маркеров. Это не перенос reasoning в итог при незавершённом размышлении.
- Включён полный host expert pool; READY отклоняется, если оставшиеся эксперты не покрыты RAM. CPU/GPU-перенос может использовать штатный pinned pool. Полный пул экспертов сам по себе не доказывает резидентность всех остальных таблиц.
- Отображение неизвестного объёма expert cache больше не подставляет нулевой размер.
- Для оставшейся CPU-таблицы embeddings собран отдельный native с pinned RAW-копией. CPU-проверки подтвердили точные байты и порядок освобождения. Пересобраны две host TU, 18 других link inputs сохранены, фактический GPU fatbin побайтно совпал с исходным. Новый native прошёл ограниченную реальную проверку запуска, полного покрытия экспертов в RAM/VRAM, признака `embedding_ram=1` и API с непустым итоговым ответом. Старые GPU/model receipts при этом не переименованы в новые прогоны.

На трёх коротких прогретых API-задачах на AVX1/P40 наблюдалось около **5–6 ток/с**. Это ограниченный локальный результат с корректным итоговым ответом, не парное измерение общего ускорения и не гарантия для других запросов или заполненного контекста. Экспериментальная MiniMax не оставлена выбранным локальным профилем; веса не поставляются вместе с движком.

Загрузка mmproj-файла ещё не означает готовую CPU-vision-интеграцию: нужны собственные encode, формат image tokens и native transport. Совместимый MiniMax Q2 DSpark пока не квалифицирован. Из этих изменений не выводится общий процент ускорения или готовность всех моделей.

**Проверки classic Strata, native E4:** 27 GPU-сценариев, включая побитное сравнение 5201 DenseF32-размера; два greedy-прогона по 192 токена совпали с эталоном, sampled32 завершился. T12 реально выполнялся; обычный API также проверен. Эти receipts относятся к classic Strata и не выдаются за новые проверки MiniMax native. Неизменённые квалификации переиспользуются явно.

Для Swift отдельно проверен реальный CPU image bridge на малом синтетическом изображении. Это функциональная проверка, не оценка скорости или качества на произвольных изображениях.

Это ограниченные функциональные и численные проверки, не оценка качества, распределения sampling или скорости на заполненном контексте. Фикс графов не обобщается на batch/pipeline, lookup-chain и другие backends. Формат/forced tools не является constrained decoding; полная проверка свойств JSON Schema требует необязательного `jsonschema`.

Общий процент ускорения и «абсолютно самые быстрые настройки» здесь не заявляются. MTP/lookup, AVX1 и другие возможности, уже присутствующие в stock, сами по себе не приписываются форку.

Основа — [Strata](https://github.com/Niko1221/Strata); MiniMax native — [Project Maya](https://github.com/mw00/project-maya). Исходные лицензии и уведомления ggml/Pascal overlay сохраняются. **Built with MiniMax M3.1-Flash.**
