# Strata Legacy GPU

**EN.** Strata for Windows x64, AVX1/Ivy Bridge and NVIDIA Pascal. The Swift 1.5 IQ3_S profile is tested on a Tesla P40 with dual Xeon E5-2697 v2. Serve local models through an OpenAI-compatible API. The installer contains the runtime and accepts your own GGUF files.
